# Security policy

## Supported versions

Security fixes are applied to the latest released version of Spakoi.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's private
security advisory form:

https://github.com/VictoriaAppDeveloper/spakoi/security/advisories/new

Include the affected version, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within seven days.

Spakoi's strict mode is intended to prevent accidental schedule changes. It is
not a security boundary against an administrator or a user with root access.
